# MULTI1Dvisual 应用图标

图标延续 VISSOP 的深色圆角底和青绿色。双峰剖面构成 MULTI1Dvisual 的 M，曲线右端的琥珀色小峰帮助区分两款软件。

原图由内置 ImageGen 生成，保存在 [1254 像素透明 PNG](multi1dvisual-master.png)。[512 像素 PNG](multi1dvisual.png) 用于 Qt 窗口和 Linux 图标主题，[多尺寸 ICO](multi1dvisual.ico) 用于 Windows 可执行文件和安装向导。

生成提示词如下。

> 为 Linux 科学可视化软件 MULTI1Dvisual 设计一枚方形桌面图标。深靛蓝圆角方块上，用粗实的青绿色一维剖面曲线形成清晰的大写 M，两座尖峰间有一道谷，右侧留一小段暖琥珀色峰顶。构图居中，简洁平面几何，大面积留白，缩至 24 像素仍清楚，圆角外透明，无文字、坐标轴、网格、阴影或光效。
