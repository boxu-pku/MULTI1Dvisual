## 项目简介

MULTI1D可视化工具是一个专门用于可视化MULTI1D仿真程序输出结果的GUI应用程序。该工具具有以下特点：

- **直接读取二进制文件**：无需使用`writeAscii.py`预先转换，直接读取fort.10二进制文件
- **丰富的可视化类型**：支持空间图、时间图、热图三种主要可视化方式
- **专业的科研绘图**：符合科研论文规范的图表样式
- **友好的用户界面**：基于PyQt5的现代化界面设计
- **完整的中英文支持**：界面语言可自由切换
- **强大的数据导出**：支持图片和数据多种格式导出
- **代码录制功能**：录制GUI操作，生成独立Python回放脚本，支持批处理和脚本定制

## 主要功能

### 1. 数据源
- **直接读取** fort.10 二进制文件
- 无需使用 writeAscii.py 预先转换为 ASCII 格式
- 复用 scanFile.py 的解析逻辑
- 支持多文件同时加载和切换

### 2. 三类可视化图表

#### 空间图 (Spatial Plot)
绘制变量随位置/网格的变化曲线。

**功能特性**：
- 支持选择多个时刻进行叠加显示
- 自定义每个时刻的颜色、线型、线宽
- 全选、反选、清除选择功能
- 统一样式应用：为选中的时刻设置统一的颜色和线型
- 支持线性/对数坐标轴
- 支持位置单位切换（cm, um）
- 可删除/恢复特定时刻的数据

**典型应用场景**：
- 观察某一时刻物理量在空间上的分布
- 对比不同时刻的空间分布变化
- 分析冲击波传播过程

#### 时间图 (Temporal Plot)
绘制变量随时间的演化曲线。

**功能特性**：
- **全局变量模式**：绘制全局时间变量（ENIE, ENII, ENKI等）
- **网格模式**：绘制特定网格的时间演化
- 支持对数坐标轴（X轴/Y轴）
- 支持时间单位切换（s, ns）
- 支持多网格同时显示
- 可删除/恢复特定网格的数据

**典型应用场景**：
- 观察系统能量演化
- 监测特定位置的温度/密度变化
- 分析能量吸收和转换过程

#### 热图 (Heatmap)
绘制时空分布热图。

**功能特性**：
- 支持插值处理网格数不一致的情况
- 多种颜色映射方案（jet, viridis, plasma, inferno等）
- 支持对数色标
- 位置标记线和时间标记线
- 自定义颜色范围（vmin, vmax）
- 坐标轴方向可切换

**典型应用场景**：
- 观察物理量的时空演化
- 识别波前传播路径
- 分析温度/密度分布格局

### 3. 数据导出

**图片导出**：
- 支持格式：PNG, PDF, SVG
- 可设置DPI（默认300）
- 保持科研论文级别的图像质量

**数据导出**：
- ASCII格式（SCout.txt, TSout.txt）
- CSV格式（便于Excel、MATLAB等工具分析）

### 4. 高级工具

#### 交互式标注工具（Annotation Tool）
- 支持直线、箭头、矩形、椭圆、文字标注
- 可自定义颜色、线型、线宽、透明度
- 标注列表管理（查看、删除）
- 导出带标注的图片

#### 极值寻找工具（Extreme Finder）
- 从热图中提取分布曲线
- 自动检测极大值/极小值
- 可自定义极值搜索范围
- 显示导数曲线辅助分析
- 支持固定位置/固定时间两种提取模式

#### 热图分布提取工具（Heatmap Profile Extractor）
- 在热图上绘制任意直线
- 自动提取沿线的数据分布
- 显示分布曲线图
- 导出分布数据

#### 代码录制工具（Code Recorder）
- 录制GUI中的可视化操作（打开文件、空间图、时间图、热图、极值寻找、分布提取）
- 生成独立的Python回放脚本，无需GUI即可复现所有操作
- 支持批处理和脚本自定义
- 生成的脚本仅依赖 `numpy`、`matplotlib`、`scipy` 和 `Fort10Parser`
- 自动保存所有图片，输出与GUI完全一致

### 5. 用户界面

**界面特性**：
- 现代化的PyQt5界面
- 分屏布局：左侧控制面板，右侧绘图画布
- 完整的菜单栏：文件、视图、导出、工具、设置、帮助
- 状态栏实时显示操作状态
- 工具栏快捷操作
- 可调节的面板大小

**语言支持**：
- 完整的中英文双语界面
- 可通过菜单随时切换语言
- 语言设置持久化保存

6. **设置参数**：选择变量、单位等绘图参数
7. **绘制图表**：点击"绘制"按钮
8. **保存结果**：使用保存/导出按钮保存图片或数据

## 详细使用说明

### 空间图详细说明

#### 界面布局
- **左上角**：变量选择（选择要绘制的物理量）
- **左中**：单位设置（X轴位置单位、时间单位）
- **左下**：时刻选择（多选列表框）
- **右侧**：样式设置、坐标设置、操作按钮
- **底部**：绘图区域

#### 绘图步骤

1. **选择变量**：从下拉菜单中选择要绘制的变量（如温度T、密度R等）
2. **设置单位**：
   - X轴单位：cm（厘米）或 um（微米）
   - 时间单位：s（秒）或 ns（纳秒）
3. **选择时刻**：
   - 点击选择单个时刻
   - 按住Ctrl点击多选时刻
   - 使用"全选"、"反选"、"清除"按钮快速选择
4. **设置样式**（可选）：
   - 选中要设置的时刻
   - 选择颜色、线型、线宽
   - 点击"应用样式到选中项"
5. **设置坐标轴**（可选）：
   - 勾选"LOG X轴"使用对数X轴
   - 勾选"LOG Y轴"使用对数Y轴
   - 设置X/Y范围（取消勾选"自动"后可手动输入）
6. **绘制**：点击"绘制"按钮

#### 高级功能

**删除特定时刻**：
1. 在时刻列表中选中要删除的时刻
2. 点击"删除选中"按钮
3. 时刻变灰表示已删除，不再绘制
4. 可通过"取消删除"恢复

**样式快速应用**：
1. 选中多个时刻
2. 设置统一的颜色和线型
3. 点击"应用样式到选中项"
4. 所有选中的时刻应用相同样式

---

### 时间图详细说明

#### 两种绘图模式

**全局变量模式**：
- 用于绘制全局时间变量（系统级积分量）
- 变量包括：ENIE（电子内能）、ENII（离子内能）、ENKI（动能）等
- 适用于观察系统整体的能量演化

**网格模式**：
- 用于绘制特定网格（空间位置）的时间演化
- 需要先选择空间变量，然后选择网格编号
- 适用于观察局部位置的物理量变化

#### 绘图步骤

**全局变量模式**：
1. 选择"全局时间变量"单选按钮
2. 从变量下拉列表中选择全局变量
3. 设置时间单位（s或ns）
4. 设置颜色、线型
5. 设置坐标轴选项
6. 点击"绘制"

**网格模式**：
1. 选择"网格时间演化"单选按钮
2. 从变量下拉列表中选择空间变量
3. 在网格列表中选择网格（可多选）
4. 设置样式（可为不同网格设置不同样式）
5. 点击"绘制"

#### 多网格管理

**选择网格**：
- 单击选择单个网格
- Ctrl+单击多选
- Shift+单击连续选择
- 使用"全选"、"反选"、"清除"按钮

**设置样式**：
1. 选中要设置的一个或多个网格
2. 选择颜色、线型
3. 点击"应用样式"
4. 选中的网格会应用新样式

**删除/恢复网格**：
- 删除：选中网格后点击"删除选中"，网格不会在图中显示
- 恢复：选中已删除的网格，点击"取消删除"

### 热图详细说明

#### 界面布局
- **左上角**：变量选择
- **左中**：坐标设置（方向、单位）
- **左下**：颜色设置（颜色映射、范围）
- **右侧**：绘图区域和标记工具

#### 绘图步骤

1. **选择变量**：从下拉菜单中选择要绘制的变量
2. **设置坐标方向**：
   - 时间在横轴：X=时间，Y=位置
   - 位置在横轴：X=位置，Y=时间
3. **设置单位**：
   - 位置单位：cm或um
   - 时间单位：s或ns
4. **设置颜色映射**：
   - 选择颜色映射方案（jet, viridis, plasma等）
   - 设置颜色范围（vmin, vmax）
   - 勾选"对数色标"使用对数颜色映射
5. **绘制**：点击"绘制热图"

#### 添加标记线

**位置标记线**：
1. 输入位置值（可多个，用逗号分隔）
2. 点击"添加位置标记"
3. 在热图上显示垂直线标记

**时间标记线**：
1. 输入时间值（可多个，用逗号分隔）
2. 点击"添加时间标记"
3. 在热图上显示水平线标记

**清除标记**：
- 点击"清除位置标记"清除所有位置标记线
- 点击"清除时间标记"清除所有时间标记线

## 工具详解

### 交互式标注工具

**启动方式**：菜单 → 工具 → 标注工具

**使用步骤**：
1. 启动标注工具
2. 从工具类型下拉列表中选择标注类型：
   - 直线：绘制直线
   - 箭头：绘制带箭头的线
   - 矩形：绘制矩形框
   - 椭圆：绘制椭圆/圆
   - 文字：添加文字说明
3. 设置样式属性：
   - 颜色：点击颜色块选择颜色
   - 线宽：调整线条粗细
   - 线型：选择实线、虚线等
   - 透明度：调整不透明度
4. 在图表上操作：
   - 直线/箭头/矩形/椭圆：按住鼠标左键拖拽
   - 文字：单击位置，在弹出对话框中输入文字
5. 管理标注：
   - 在右侧列表中查看所有标注
   - 选中标注后点击"删除选中"删除
   - 点击"刷新列表"更新列表显示
6. 导出：点击"导出带标注图片"保存结果

**提示**：
- 标注工具需要先在当前标签页绘制图表后才能使用
- 关闭标注工具对话框会自动断开鼠标事件
- 标注保存在内存中，关闭主程序后会丢失

### 极值寻找工具

**启动方式**：菜单 → 工具 → 极值寻找工具

**功能说明**：
- 从热图中提取沿固定位置或固定时间的分布曲线
- 自动检测曲线的极大值和极小值
- 显示极值的位置、数值等信息

**使用步骤**：
1. **添加Profile**：
   - 选择提取类型：
     - 固定位置（沿时间）：在固定位置提取随时间的变化
     - 固定时间（沿位置）：在固定时刻提取随位置的变化
   - 输入坐标值（可多个，用逗号分隔）
   - 点击"添加Profile"
2. **设置极值范围**（可选）：
   - 在Profile列表中选中某个Profile
   - 点击"范围"列的单元格
   - 输入范围（格式：min,max）
   - 点击"全范围"恢复全范围搜索
3. **设置极值选项**：
   - 勾选"寻找极大值"：检测极大值
   - 勾选"寻找极小值"：检测极小值
   - 勾选"显示导数曲线"：显示导数辅助分析
   - 勾选"显示图例"：显示图例
4. **提取并寻找极值**：
   - 点击"提取并寻找极值"按钮
   - 查看"热图"、"分布曲线"、"导数曲线"三个标签页的结果
5. **保存结果**：
   - 点击"保存图片"保存图表
   - 点击"导出数据"导出极值数据
6. **配置管理**：
   - 点击"保存为默认配置"保存当前设置
   - 点击"加载默认配置"恢复之前保存的设置

**极值信息说明**：
- 【极大值】/【极小值】：极值类型
- 位置/时间：Profile的位置或时间
- 极值在...：极值出现的坐标位置
- 值=：极值的数值

### 热图分布提取工具

**启动方式**：菜单 → 工具 → 热图分布提取工具

**功能说明**：
- 在热图上绘制任意直线
- 自动提取沿线的数据分布
- 显示分布曲线和数值

**使用步骤**：
1. 确保已在热图标签页绘制了热图
2. 启动热图分布提取工具
3. 点击"开始提取"按钮
4. 在热图上按住鼠标左键拖拽绘制直线
5. 释放鼠标后自动显示分布曲线对话框
6. 在对话框中可以：
   - 查看分布曲线
   - 点击"保存图片"保存分布图
   - 点击"导出数据"导出分布数据（CSV格式）
7. 如需提取另一条线：
   - 保持工具对话框打开
   - 重复步骤3-5
8. 完成后：
   - 点击"清除标记"清除热图上的提取线
   - 点击"停止"停止提取模式
   - 或直接关闭对话框

**提示**：
- 提取线在热图上显示为白色线条
- 分布曲线对话框显示沿线的距离和对应的数值
- 导出的CSV文件包含两列：距离和数值

### 代码录制工具

**启动方式**：菜单 → 工具 → 代码录制工具（快捷键 Ctrl+R）

**功能说明**：
- 录制GUI操作，生成可独立运行的Python脚本
- 支持录制所有可视化操作类型
- 生成的脚本可在无GUI环境下运行（使用Agg后端）

**使用步骤**：
1. 启动代码录制工具
2. 点击"开始录制"
3. 在GUI中执行可视化操作（打开文件、绘制空间图/时间图/热图、使用极值寻找工具等）
4. 操作完成后点击"停止录制"
5. 点击"生成脚本"，选择保存路径
6. 运行生成的脚本：`python <脚本名>.py`

**录制的操作类型**：
- 打开文件
- 空间图绘制（变量、时刻、样式、坐标设置）
- 时间图绘制（全局变量模式、网格模式）
- 热图绘制（变量、颜色映射、标记线）
- 极值寻找（Profile提取、范围设置、极值检测）
- 热图分布提取（沿线数据提取）

**提示**：
- 生成的脚本默认保存为 `<数据文件名>_replay.py`
- 脚本会自动保存所有图片为PNG格式（300 DPI）
- 极值寻找会生成多个图片：热图+标记、分布曲线、导数曲线

## 变量列表

### 空间变量（Spatial Variables）

| 变量名 | 英文名称 | 描述 | 单位 |
|---------|----------|------|------|
| XC | Centroid | 质心坐标 | cm |
| DENE | Electron Density | 电子密度 | cm⁻³ |
| EE | Electron Energy | 电子能量 | erg |
| EI | Ion Energy | 离子能量 | erg |
| P | Pressure | 压力 | dyn/cm² (内部存储；UI 默认显示 GPa，可切换 Mbar) |
| PT | Total Pressure | 总压 | dyn/cm² (内部存储；UI 默认显示 GPa，可切换 Mbar) |
| R | Density | 密度 | g/cm³ |
| T | Electron Temperature | 电子温度 | eV |
| TI | Ion Temperature | 离子温度 | eV |
| ZI | Ion Charge | 离子电荷数 | - |
| TR | Radiation Temperature | 辐射温度 | eV |

## 常见问题

### Q1: 程序无法启动怎么办？

**可能原因和解决方案**：

1. **Python版本过低**
   - 检查Python版本：`python --version`
   - 确保版本≥3.7，建议使用3.8+

2. **依赖库未安装**
   - 重新安装依赖：`pip install PyQt5 numpy matplotlib scipy pandas`

3. **路径问题**
   - 确保在项目根目录下运行程序
   - 检查工作目录是否正确

4. **查看日志**
   - 日志文件位置：`~/.MULTI1D可视化工具/logs/`
   - 查看最新的日志文件了解详细错误信息

---

### Q2: 无法打开fort.10文件？

**可能原因和解决方案**：

1. **文件格式不正确**
   - 确认文件是标准的fort.10二进制格式
   - 检查文件是否损坏
   - 尝试使用原始的scanFile.py验证文件

2. **文件路径问题**
   - 确保文件路径中没有特殊字符
   - 尝试将文件复制到简单路径下

3. **权限问题**
   - 确保对文件有读取权限
   - Windows用户：以管理员身份运行程序

---

### Q3: 图表显示异常？

**可能原因和解决方案**：

1. **数据范围问题**
   - 尝试启用对数坐标轴
   - 调整颜色范围（vmin, vmax）
   - 启用"自动"范围

2. **内存不足**
   - 关闭其他应用程序释放内存
   - 减少绘制的数据量
   - 尝试导出数据后用其他工具分析

3. **Matplotlib后端问题**
   - Windows用户：确保安装了PyQt5
   - Linux用户：`export MPLBACKEND=Qt5Agg`

---

### Q4: 导出的图片质量不高？

**解决方案**：

1. **增加DPI设置**
   - 在Config.py中修改DEFAULT_SAVE_DPI
   - 推荐设置为300或600

2. **使用矢量格式**
   - 导出为PDF或SVG格式
   - 矢量格式可无损缩放

3. **调整图表大小**
   - 全屏显示后再保存
   - 或在Config.py中调整FIGURE_SIZE

---

### Q5: 语言切换后部分界面仍是中文？

**解决方案**：

1. **重启程序**
   - 某些界面元素需要重启才能生效
   - 关闭程序后重新打开

2. **清除语言配置**
   - 删除`~/.MULTI1D可视化工具/language_config.json`
   - 重新启动程序选择语言

---

### Q6: 如何处理大规模数据？

**建议**：

1. **选择性绘图**
   - 只绘制必要的时刻或网格
   - 使用数据导出功能导出后用专业工具分析

2. **调整插值参数**
   - 减少热图的插值点数
   - 在Config.py中调整相关参数

3. **使用数据采样**
   - 导出数据后使用MATLAB/Python等工具进行采样分析
